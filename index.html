Overview

What are Functions?

Python functions are reusable blocks of code designed to perform a specific task. They help programmers organize code, reduce repetition, and improve readability and maintainability.

Functions are defined using the def keyword, followed by the function name, parentheses, and a colon. The code inside the function is indented beneath the definition.

Classification

Types of Functions in Python

Python functions are generally classified into two main types:

1. Built-in Functions

Functions already provided by Python that can be used directly without creating them. These are predefined and available for immediate use.

2. User-Defined Functions

Functions created by the programmer using the def keyword to perform specific tasks according to the program's requirements.

User-Defined

User-Defined Functions

These are functions created by the programmer using the def keyword. User-defined functions are created to perform specific tasks according to the program's requirements.

Syntax

Creating Functions in Python

Functions are created using the def keyword followed by:

Function name, Parentheses (), Colon : and Function body (indented code block)

General Syntax

def function_name(parameters): # Function body statements return value

Example Program

def greet(): print("Hello, World!") greet() # Output: Hello, World!
Return Statement

What is the Return Statement?

In Python, the return statement terminates the execution of a function and optionally returns a value to the caller.

Key Points

return ends the function immediately. It sends a value back to the caller. A function can have multiple return statements. If no return is used, Python returns None by default.

Example 1 — Single Return Value

def add(a, b): return a + b

Example 2 — Multiple Return Values

def calculate(a, b): return (a + b, a - b, a * b) sum_, diff, product = calculate(10, 5) print(sum_) # 15 print(diff) # 5 print(product) # 50
Four Types

Classification Based on Arguments and Return Values

User-defined functions can be further classified into four types based on whether they accept arguments and whether they return values.

Type Arguments Return Value
Type 1 No Arguments No Return Value
Type 2 With Arguments No Return Value
Type 3 No Arguments With Return Value
Type 4 With Arguments With Return Value

1. No Arguments and No Return Value

A function that neither accepts any input from the caller nor returns any value back. It simply performs a specific task when called.

def greet(): print("Welcome to Python Programming") greet() # Output: Welcome to Python Programming

2. With Arguments and No Return Value

A function that accepts input values (arguments) from the caller but does not return any value back. It performs a task using the given inputs.

def greet(name): print("Hello", name) greet("Ravi") # Output: Hello Ravi

3. No Arguments and With Return Value

A function that does not accept any input from the caller but returns a value after performing its task.

def get_number(): return 100 num = get_number() print(num) # Output: 100

4. With Arguments and With Return Value

A function that accepts input values from the caller, processes them, and returns the result back to the caller.

def add(a, b): return a + b result = add(10, 20) print(result) # Output: 30
